# Redis Chapter 1

Basic Redis and MongoDB connectivity test.

## Endpoints

```bash
# Test Redis connection
curl http://localhost:3000/redis

# Test MongoDB connection
curl http://localhost:3000/mongo
```

## What You Learn

- How to connect to Redis using `ioredis`
- How to use `PING` to test connectivity
- Docker setup for Redis and MongoDB

## Run

```bash
npm install
npm run dev
```
